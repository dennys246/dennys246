- **[HRfunc](https://github.com/dennys246/HRfunc)**: fNIRS hemodynamic-response modeling toolkit; 22 releases, ~18K PyPI downloads. First-author paper in [*Neurophotonics* (2025)](https://doi.org/10.1117/1.NPh.13.S1.S17801)
